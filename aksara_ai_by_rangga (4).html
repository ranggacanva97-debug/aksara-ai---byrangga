AKSARA AI

by RANGGA

"Teman berpikir, tanpa batas."

AKSARA AI adalah asisten kecerdasan buatan pribadi yang dirancang untuk membantu berpikir, membaca dan menganalisis gambar, menulis, meneliti, membuat visual, hingga menyusun daftar pustaka ilmiah secara gratis tanpa memerlukan API key, kartu kredit, maupun akun developer.

Transparansi Privasi & Pemrosesan Data

  • Riwayat Percakapan: Disimpan sepenuhnya di penyimpanan lokal browser Anda (localStorage) dan tidak disimpan di database server kami.
  • Analisis Gambar & OCR: Gambar yang Anda unggah diproses menggunakan model vision multimodal gratis serta ekstraksi teks lokal (Tesseract.js) langsung di browser Anda untuk membaca soal, dokumen, maupun tangkapan layar.
  • Mode Chat Cloud vs Lokal: Pada Mode Cloud Gratis, pertanyaan dikirim ke endpoint inferensi publik gratis. Pada Mode Lokal (WASM/WebGPU), model dijalankan 100% di perangkat Anda setelah diunduh ke cache browser.
  • Pembuatan Gambar: Deskripsi visual diproses melalui layanan generator gambar publik gratis tanpa API key.
  • Pencarian Web & Referensi: Kata kunci pencarian dikirim ke API publik terbuka (Crossref, OpenAlex, dan Wikipedia) untuk mengambil metadata jurnal, artikel, dan tautan sumber asli tanpa mengarang referensi.
